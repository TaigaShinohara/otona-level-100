# オトナレベル100

大人が、スキマ時間に「知らないと恥ずかしい常識」を1日5問だけ解くことで、昨日より大人になったと実感できるアプリ。

- 形式：4択クイズ＋暗記カード、1セット5問（新規3＋復習2）・約1分
- レベル：Lv.1〜100、レベルは絶対に下がらない。間違えても責めない
- 復習：Leitner方式（1日→3日→7日→21日、3回連続正解＋Box3で卒業、卒業後は抜き打ちで再登場）
- カテゴリ（P0）：敬語・言葉づかい／マナー・冠婚葬祭／漢字・日本語／道路標識・交通／社会・お金・手続き
- 問題は公的一次出典（警察庁・文化庁・国税庁など）を正本に作成し、全問に出典を明記

## 状態

開発中（v0.3.3）。問題データは現在20問の見本で、本データ（P0 約600問）は制作中。
設計の正本は `docs/設計_v1.2.md`、見た目の方針は `docs/ART_DIRECTION.md`。

## 技術

- Android（Kotlin、プログラム的View生成、Compose不使用）、minSdk 26 / targetSdk 35
- 権限ゼロ・アカウントなし・通信なし。進捗は端末内（SharedPreferences）にのみ保存
- 署名鍵はリポジトリに含めない（`.local/` は gitignore 済み）
