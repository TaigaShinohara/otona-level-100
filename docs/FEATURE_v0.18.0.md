# v0.18.0 ゲームデザイン改善（厳格レビュー全件対応）

起点：docs/GAME_DESIGN_REVIEW_2026-11-28.md の改善案1〜6＋本人の追加指示「序盤は手厚く楽しませ離脱を防ぐ」（案7）。
方針：ストレスの急所は「失敗の後遺症」。失敗しても失うものを小さくし、戻ってきた日と最初の1週間を得にする。

## 案1 ミスの緩和＋卒業取消の廃止
- 誤答時の Leitner 段（box）は「1つだけ下がる」（最低1）。翌日に再出題される点は不変（訂正は新鮮なうちに）。
- 卒業した問題の抜き打ち失敗では卒業を取り消さない。「要確認」フラグ（ProgressStore.confirm_ids）を立て、3日後に確認として再登場（ReviewLogic.onSpotCheckMiss）。正解すれば通常の21日周期に復帰しフラグ解除、また間違えても再スケジュールのみで降格しない。
- 結果：本棚の本が減ることは二度とない（「レベルは下げない」の約束と一致）。

## 案2 復習XPの同額化
- XP_REVIEW_CORRECT 5→10（新規と同額）。習熟して復習比率が上がっても、1セットの伸びは鈍らない。

## 案3 復帰ウェルカム
- 前回のデイリー完了から2日以上空いた日は、デイリーの復習枠が2問→3問（借金の融解を少し早める）。XPは案2で同額なので損はない。
- ホームの吹き出しは復帰日に「おかえり！久しぶりだね。無理なくいこう」が最優先。借金の量は今まで通り一切見せない。

## 案4 今日の量を選べる
- ホームの主ボタンの下に「かるく3問で はじめる」（おかわり時は「かるく おかわり3問」）。startSession(size=3)。復習最大2＋新規で3問編成、カード保証と季節枠は5問時と同じ規則。

## 案5 中盤の小ご褒美
- フクロウの節目アクセサリー：Lv.40で金のバッジ（腹の星章）、Lv.50で小さな冠（OwlGrowth.accessoryFor、全パス共通）。到達したセットの結果画面・第4幕で「新しい飾りがついた！」と知らせる。
- 10レベルごとの節目：レベルアップした結果画面の第3幕に「Lv. ○○ 到達！大きな節目！」を追加。

## 案6 波のピーク適格化
- SessionDesign.orderWave のピーク（4問目）は新規問題の中で最も難しいものだけから選ぶ。新規がない場合のみ従来通り全体から。難度3の復習は中盤の安全地帯に残る。

## 案7 序盤ブースト（本人の追加指示）
- 最初の1セットは新規問題が全問「やさしい」（difficultyMix(sessionsDone=0) = 100/0/0）。2〜7セット目も やさしい85%/ふつう15% で、レベル帯の配分より優先される。
- 若葉ボーナス：Lv.10未満の間、正解（カウント対象）ごとに +5 XP。Lv.5（ヒナ進化）は最短2日目に届く計算。
- ホームの吹き出し：初回は歓迎文、最初の1週間は序盤プール（「間違えても大丈夫。段が1つ下がるだけ」等）が日替わりより優先。
