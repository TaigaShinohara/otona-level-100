## 敬語・言葉づかい

**Q1.** 上司の行動を言うとき、正しいのは？
1. 部長がおっしゃいました
2. 部長が申されました
3. 部長がご覧になられました
4. 部長が参られました
→ 正解：1
解説：「おっしゃる」は「言う」の尊敬語。「申す」は自分の行為に使う謙譲語なので目上には使わない。
恥場面：会議で上司の発言を引用するとき、ここを間違えると一番目立つ。
出典：文化庁「敬語の指針」

**Q2.** 目上の人に使うべきではない挨拶は？
1. お疲れ様です
2. ご苦労様です
3. お世話になっております
4. よろしくお願いいたします
→ 正解：2
解説：「ご苦労様」は目下へのねぎらいの言葉。目上には「お疲れ様」が無難。
恥場面：取引先へのメール冒頭で使うと、失礼だと受け取られることがある。
出典：文化庁「敬語の指針」

## マナー・冠婚葬祭

**Q3.** 結婚式のご祝儀で避けるべき金額は？
1. 1万円
2. 2万円
3. 3万円
4. 5万円
→ 正解：2
解説：2万円は「割れる＝別れる」を連想させるため慶事では避けるのが一般的。包む場合は2万円＋品物などで調整する。
恥場面：受付で渡す金額は、後からでも長く覚えられる。
出典：一般的な冠婚葬祭マナー（幅がある領域のため断定せず「一般的」と表記）

**Q4.** 葬儀で香典袋に書く表書きとして一般的なのは？
1. 御祝
2. 御霊前
3. お見舞い
4. 御中元
→ 正解：2
解説：通夜・葬儀では「御霊前」が広く使われる（宗派により「御仏前」を使う場合がある）。
恥場面：受付で表書きを見られる場面。宗派が分かる場合はそれに合わせる。
出典：一般的な冠婚葬祭マナー（宗派差ありと明記）

## 漢字・日本語

**Q5.** 「月極駐車場」の読みは？
1. げっきょく
2. つきぎめ
3. げっき
4. つききょく
→ 正解：2
解説：「月極」は「つきぎめ（月ごとに決める）」の熟字訓。
恥場面：不動産の話で「げっきょく」と読むと、その場で訂正されがち。
出典：常用漢字表・辞書類

**Q6.** 「脆弱」の読みは？
1. きじゃく
2. ぜいじゃく
3. さいじゃく
4. もろじゃく
→ 正解：2
解説：「脆」は音読みで「ゼイ」。「脆弱性（ぜいじゃくせい）」は仕事でも頻出。
恥場面：会議の資料読み上げでつまずくと、内容以前に目立つ。
出典：常用漢字表

## 道路標識・交通

**Q7.** 青い円に白い矢印が描かれた標識の意味は？
1. 一方通行
2. 指定方向以外進行禁止
3. 車両通行止め
4. 左折可
→ 正解：2
解説：矢印の方向以外へは進めないことを示す規制標識（本データでは画像付きで出題する）。
恥場面：矢印と逆方向に進むと違反になるだけでなく危険。
出典：警察庁 道路標識

**Q8.** 「駐車」と「停車」の違いで正しいのは？
1. 停車は5分以内なら何をしてもよい
2. 停車は人の乗り降りや短時間の荷物の積み下ろしなど、すぐに運転できる状態
3. 駐車禁止の場所では停車も常に禁止
4. 停車中はエンジンを切らなければならない
→ 正解：2
解説：停車は「直ちに運転できる状態での短時間の停止」。駐車禁止場所でも停車は可能な場合が多い。
恥場面：「ちょっとだけ」のつもりの駐車が違反になる典型パターン。
出典：道路交通法

## 社会・お金・手続き

**Q9.** 「源泉徴収」とは？
1. 給与から税金があらかじめ差し引かれる仕組み
2. 年末に自分で税金を一括で払う仕組み
3. 副業収入だけにかかる税金
4. 住民税の別名
→ 正解：1
解説：会社が給与から所得税を天引きして国に納める仕組み。年末調整はその精算。
恥場面：給与明細の話題で「手取りとの差」を説明できないと詰まる。
出典：国税庁

**Q10.** 国民年金（基礎年金）の受給開始年齢は原則？
1. 60歳
2. 63歳
3. 65歳
4. 70歳
→ 正解：3
解説：原則65歳。希望すれば60〜64歳への繰上げ（減額）や66〜75歳への繰下げ（増額）が選べる。
恥場面：親の年金や自分の将来の話で、土台の数字がずれていると話が噛み合わない。
出典：厚生労働省・日本年金機構
