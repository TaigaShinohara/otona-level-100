# 実機スクショ起点の直し記録（v0.3.1・2026-11-19）

経緯：本人が Simple Glass チャットで適用前後の実機スクショを提示し、指摘3点に同意＋追加印象「単調で安っぽい」。このチャット（アプリ担当）で4点を修正。

| # | 指摘 | 原因と直し方 |
|---|---|---|
| 1 | ダークで画面タイトルがステータスバーに被る | targetSdk 35 の edge-to-edge で、コンテンツ側にインセット処理が無かった。背景は全面のまま、コンテンツ列にステータスバー／ナビバーのインセット padding を適用（ライト・ダーク共通）。ライト側はステータスバーアイコンを暗色化（LIGHT_STATUS_BAR） |
| 2 | カテゴリの進捗バーが空に見える | バーは「卒業率」表示だったため、解いていても卒業0なら0%だった（仕様の見せ方の問題）。バーを「解いた割合」に変更し、塗りをカテゴリ別アクセント色にしてトラックと分離。読み上げ名も実態に合わせて更新 |
| 3 | 「苦手だけ5問」が無効化に見える | 副ボタンをガラス＋淡い文字にしていたのが原因。ベタ寄りの強いティント＋縁＋太字の濃色文字に変更し、押下状態も定義 |
| 4 | 画面ごとに単調で安っぽい | 地（紺＋ガラス）だけでティント／ベタの配分が無かった。現行構成のまま：カテゴリに淡色ティント＋頭文字チップ＋色つきバーを追加、出題ヘッダーにカテゴリ色ピル、復習画面の件数をティントチップ化、ダーク側の紺を一段明るく。色分けの採用は ART_DIRECTION v1.1 に記録 |

未確認：ライト側ガラス版の実機の見え方（スクショはダークのみ確認済み）、インセット修正後の実機確認 — ともに実機待ち行列。
検証：ビルド成功、単体テスト12件合格、署名は同一証明書（上書きインストール可）。

## 追記：v0.3.2（同日・方針修正）
本人の追加の気づき「UIに直接色を塗るとガラスとしては安っぽい」を受け、4点目のやり方を修正。原則：**色は面に塗らず、光で透かす**（スキル本体にも追記済み）。
- カテゴリの頭文字チップ：淡色ベタ → 読み物ガラスの円＋文字だけカテゴリ色
- 出題ヘッダーのカテゴリピル：淡色ベタ → ガラス＋小さな色ドット＋紺文字
- 据え置き（機能点のベタとして正当）：進捗バーのカテゴリ色の塗り、選択中タブ、主ボタン、復習件数チップ（主要数値・小面積）
