# minimal 審査記録 v0.16.0（2026-11-28）

本人の指示「minimalスキルでアプリ全体のノイズを消して」を受け、全画面を棚卸しして実施。
判定軸のコンセプトは設計 v1.3 の正本：「大人が、スキマ時間に『知らないと恥ずかしい常識』を
1日5問だけ解くことで、昨日より大人になったと実感できる体験」。

## 棚卸しと仕分け（グループ単位で数える）

全35単位（ホーム12／問題7／結果6／復習6／カテゴリ4）。
必須 21／支援 9／ノイズ 5 → **ノイズ率 約14% → 0%**。

### 消したノイズ（5件）

| 項目 | 判定 | 理由 |
|---|---|---|
| ホームのアプリ名「オトナレベル100」 | ノイズ（無関係） | 開いたアプリの名前は判断材料にならない |
| 本棚カードの見出し・制覇テキスト・行ラベル | ノイズ（重複） | 本棚はパネル内の背景シーン化（本人指示）。ジャンル別進捗の数値の正本はカテゴリタブに既にある |
| ホームのフッター「1セット5問・約1分。レベルは下がりません」 | ノイズ（重複＋再表示） | 「5問」は開始ボタンと重複。「下がりません」は設計の約束だが常時表示は流れの再表示 |
| カテゴリの説明文「ジャンルをタップすると…」 | ノイズ（説明で補う型） | 各行の「挑戦」ピルが操作を示している |
| カテゴリの統計フッター「回答は通算 N 回…」 | ノイズ（統計の常時表示） | このタブの仕事（ジャンルを選ぶ）と無関係。全体進捗の正本はホーム |

### 残したもの（理由つき）

- 「あと正解 約N問 でレベルアップ」：バーは進捗の形、これは次にやることの判断材料（数字）。役割が違うので重複ではない。
- カード問題の「まず頭の中で答えてから、めくってください」：めくる操作の到達可能性のため（操作そのものでは伝わりにくい唯一の箇所）。
- 結果画面の星＋正解数：星＝気持ちの形、正解数＝事実。既存判断どおり併記を維持。
- 復習の仕組み説明：初回のみ表示＋以後はトグル内（UX3-05 で対応済み）。

## 本棚の背景化（本人指示と同時実施）

- 本棚カードを廃し、パネル下部に「書斎シーン」（ShelfSceneView）を新設：木枠＋5段の棚板、
  フクロウが一番下の棚に立つ。背景でありつつ、卒業割合で本が増える進捗表示でもある。
- 描画品質の底上げ：本の高さ・幅にばらつき、背表紙の光の筋と帯、下部の影、部分的に傾いた本、
  空きスロットは淡い輪郭から「くぼんだ影」へ（ダークで白いカプセルに見えた問題の解消）、
  棚板は上面のハイライト＋落影、両端に支柱。
- アクセシビリティ：シーンの contentDescription にジャンル別の卒業割合（％）を保持（視覚の削減≠情報の削除）。
