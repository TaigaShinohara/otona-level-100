# 問題生成プロンプト（他エージェント用）v1.1

大河が他のエージェントにそのまま渡して使うためのプロンプト。
戻ってきたシート（問題文＋正解のみ）は、パソパソ側で選択肢・解説・場面・出典照合を付けてアプリに組み込む。

v1.1（2026-11-27、本人が承認して正本化）：設計 v1.3 §3.5 のレベルデザインに合わせ、「難易度の決まり」を追加（旧版の「やさしい〜普通に寄せる」は廃止）。変更理由は既存104問のタグ付け分析（手ごわい21%では終盤Lv帯が足りない／漢字は手ごわい過多／マナー・社会は手ごわいほぼ無し）。

```
あなたは「大人の常識クイズ」の問題作成者です。以下の条件でクイズ問題を作ってください。

## 作るもの
カテゴリごとに指定数の問題。各問題は「問題文」と「正解」だけを作ってください。
選択肢・解説は不要です（後工程で付けます）。

## カテゴリ・数・出典（出典の範囲の中だけで作ること）
1. 敬語・言葉づかい：100問 — 文化庁「敬語の指針」
2. マナー・冠婚葬祭：100問 — 広く定着した公式マナー情報（諸説あるものは作らない）
3. 漢字・日本語：100問 — 常用漢字表と国語辞典に載る読み・意味・使い分け
4. 道路標識・交通：80問 — 警察庁の道路標識・交通ルール
5. 社会・お金・手続き：120問 — 国税庁・総務省・厚生労働省・日本年金機構の公式情報

## 出力形式（厳守）
- スプレッドシートに、カテゴリごとにシート（タブ）を分けて入れてください
- 列は2つだけ：A列＝問題文、B列＝正解
- 1行に1問。見出し行は入れないでください
- 問題文の末尾に、出典名を（　）で付けてください　例：（文化庁「敬語の指針」）

## 問題の決まり
- 大人が「知らないと恥ずかしい」レベルの常識だけ
- 正解が1つに決まる問題だけ作ること。諸説がある・地域差がある・制度改正で変わりやすいものは作らない
- 図形や画像がないと成立しない問題（標識の形・色を問うものなど）は、問題文の先頭にと付けること
- 同じ内容の言い換え重複は禁止。切り口を変えてください
- 人名・企業名・実在の個人情報は使わないこと

## 難易度の決まり
全体の目安は、やさしい約35%／ふつう約35%／手ごわい約30% です。カテゴリごとに次の寄せで作ってください。
- 敬語・言葉づかい：バランスよく（手ごわいは二重敬語の見分け・相手と場面で変わる使い分けなど）
- マナー・冠婚葬祭：手ごわいを厚めに。場面判断（誰に・いつ・何を）と、金額や作法の数字の細部で差がつく問題を意図的に含めること
- 漢字・日本語：やさしい〜ふつうを厚めに（読み・意味の基本を広く）。手ごわいは全体の2割まで
- 道路標識・交通：バランスよく（手ごわいは似た標識の見分け・数字の細部など）
- 社会・お金・手続き：手ごわいを厚めに。金額・期限・条件などの数字の細部と、場面判断で差がつく問題を意図的に含めること

「手ごわい」の定義：細部の知識・場面判断・応用で差がつく問題です。正解は出典の範囲で必ず1つに決まること。
言葉の紛らわしさだけで落とす、いわゆる「ひっかけ問題」は作らないでください。
```

## 戻ってきた後の工程（パソパソ側）
1. シートを受け取り、形式チェック（重複・正解の一意性・印の有無）
2. 選択肢3つ（もっともらしい誤答）・解説1行・場面1行・難易度タグを付与（タグの目安は docs/難易度タグ付け案_104問.md の判定メモ）
3. 別モデルで出典照合（工程3）→ 監修 → Questions.kt へ組み込み
4. 問題は、標識などの図形をコード描画する部品（Art.kt 方式）で表示する
