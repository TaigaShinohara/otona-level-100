# ゲームデザイン／レベルデザイン厳格レビュー（2026-11-28）

対象：v0.17.0 時点の実装（LevelSystem／ReviewLogic／SessionDesign／MainActivity のセット編成）。
観点：「ゲームとしてもっとストレスなく楽しむ」。監査は実コードと実数値に基づく。

## 総評

土台は良い。タイマーなし、ハート（ライフ）なし、レベルは絶対に下がらない、文面は責めない、1日5問で終わる。
ストレスは「失敗した瞬間」ではなく、**失敗の後遺症**に集中している。そこが急所。

## 良い所（維持すべき）

- 制限時間・ライフ・連続記録（ストリーク）での圧迫が一切ない
- レベルと称号は下がらない（levelFloor）
- 誤答でも解説が読めて学びで終われる。結果画面の文面は低スコアでも責めない

## ゲームデザインの指摘

### G1ミスの後遺症が重すぎる（Leitner の全リセット）
- 誤答すると box は 5→1、連続正解 streak は 0、翌日に再出題。21日間隔まで育てた問題でも、1回のミスで最初からやり直し。
- 卒業の条件は「3連続正解＋box3以上」で、最短でも5日・3回かかる。ミス1回でその全行程がリセットされる。
- 得られるもの（正解時XP）と失うものの非対称が大きく、「間違えたら損」が強い。開く前の心理的コストになる。

### G2卒業の取り消しが見える（本棚の本が減る）
- 卒業後の抜き打ち（21日後）で間違えると box1 に戻り、卒業数が減る。本棚は卒業割合で本が増える設計のため、**本が実際に減る**。
- 「レベルは下げない」がこのアプリの約束なのに、本棚だけが下がる。思想と矛盾する唯一の後退表示。

### G3復帰が割に合わない（二重の逆進性）
- 休むと期限切れ（due）が溜まる。デイリーは復習を2問までしか拾わないので、借金は静かに残り続ける。
- 復帰日のセットは復習中心になるが、復習の正解は XP 5（新規の半分）。戻ってきた日ほどレベルが伸びない。
- 共通思想は「戻ってきたが一番のイベント」。現行は逆で、戻ると損をする構造。

### G4波のピーク（4問目）に「落とし続けている問題」が来る
- 波は難度最大の1問を4問目に置く。難度3の復習（何度も間違えた問題）も対象なので、クライマックスが「また落ちた」になりやすい。
- 締め（5問目）がやさしいのは良いが、ピークの失敗印象が残る。

### G51日の量と気分を選べない
- 5問固定。体調が悪い日の「今日は3問でいい」ができない。開かない理由になる。
- ジャンル挑戦などの追加モードはあるが、デイリー自体の軽重は選べない。

## レベルデザインの指摘

### L1中盤のご褒美空白（Lv.30→60）
実測ペース（1日約40XP換算・全問正解に近い場合）：
- Lv.5（ヒナ）約5日／Lv.15（わかば）約3週間／Lv.30（分岐）約7週間／Lv.60（最終形）約4か月／Lv.100 約8.5か月。
- フクロウは Lv.30→60 の約2.5か月、姿が変わらない。称号も Lv.45→65 は20レベル（約7週間）同じ。
- 序盤は5日で進化するのに、中盤は節目が遠い。小さな節目（小変化・特別な褒め）が間にない。

### L2上手くなるほど1セットの価値が下がる
- 復習正解は新規の半分の XP。習熟が進むほどセット内の復習比率が上がり、1セットあたりの XP は減る。
- レベルカーブ後半（130〜150XP/レベル）と合わさると、後半は「頑張っても伸びない」感が強まる。

### L3レベルデザインが問題量に負けている
- 新規プールは基本104問。デイリーの新規枠は1日3問なので、約1か月で新規が枯れる。
- その後は補充枠（難度を見ないシャッフル）が新規枠を埋めるため、帯別難易度ミックス（Lv.85+ で手ごわい60%など）は機能しなくなる。
- 難易度設計が成立する前提は P0 約600問の量産。それまでは「帯別ミックスは序盤だけの設計」として扱うべき。

### L4節目の境界が全部同じ
- 称号帯・難易度帯・XP帯がすべて 10/25/45/65/85 で一致。変化が同時に来るか、全然来ないかの両極端になりやすい。

## 改善案（番号）

1. **ミスの緩和**：誤答時は box を1段だけ下げる（最低1）。抜き打ち失敗は卒業を取り消さず「要確認」にし、次回正解で即復帰、本は減らさない。〔G1/G2 対応・実装 小〜中〕
2. **復習XPを新規と同額（10）に**：習熟しても伸びが鈍らない。総量が気になる場合はカーブ後半を微調整。〔L2/G3 対応・実装 小〕
3. **復帰ウェルカム**：数日ぶりに開いた日は、復習を通常より多めに拾っても XP は同額（案2とセット）。due の借金は今まで通り見せない。〔G3 対応・実装 小〕
4. **今日の量を選べる**：開始前に「ふつう5問／かるく3問」。既定はふつう、選ばなければ従来通り。〔G5 対応・実装 中〕
5. **中盤の小ご褒美**：Lv.30→60 の間に小さな変化（フクロウの小物・色違い、10レベルごとの特別な紙吹雪と褒め言葉、本棚の金本など）を挟む。〔L1 対応・実装 中〕
6. **ピークの適格化**：4問目のピークは「新規の手ごわい問題」だけにし、難度3の復習はピークに置かない。〔G4 対応・実装 小〕

前提：問題の量産（P0 約600問）が進むほど L3 は解消し、帯別ミックスが本来の働きをする。
