# 問題量産パイプライン v1.0（2026-11-22 準備）

設計 v1.2 のデータ方針を実行する手順。目標は P0 約600問（IR2-3 の解消条件）。

## 配分（P0）
| カテゴリ | 目標 | 一次出典（正本） |
|---|---|---|
| 敬語・言葉づかい | 120 | 文化庁「敬語の指針」（文化審議会答申） |
| マナー・冠婚葬祭 | 120 | 冠婚葬祭の公式マナー集・神社本庁/各宗派の作法解説など一次情報。諸説ある領域は「一般的には」と幅を持たせ、人の抜き取り監修100% |
| 漢字・日本語 | 120 | 常用漢字表・文化庁「国語に関する世論調査」・辞書 |
| 道路標識・交通 | 100 | 警察庁（標識の意味・交通ルール）。標識は画像問題を含む |
| 社会・お金・手続き | 140 | 国税庁・総務省・厚労省・日本年金機構などの公式解説 |

## 工程（1バッチ＝1カテゴリ20問）
1. **生成**：出典の範囲内だけで下書きを作る。全問に prompt／選択肢4／正解／解説1行／場面1行／出典／難易度（1基礎・2標準・3応用、IR2-15）を付ける。
2. **自動チェック**：形式（選択肢の重複・正解位置の偏り・文字数）と、既存問題との重複を機械的に弾く。
3. **出典照合（別モデル）**：生成とは別モデルに全問を渡し、出典と矛盾する問・諸説が割れる問をフラグさせる。フラグは直すか落とす。
4. **人の抜き取り監修**：マナー等の諸説領域は全問、その他は抜き取り。大河の確認が要るのはここだけ（まとめて提示）。
5. **組み込み**：Questions.kt へ追加し、QuestionsTest（カテゴリ別件数・形式）を通してから版を上げる。

## データ形式の拡張（量産と同時）
- Question に `difficulty: Int` を追加（既定2）。出題の難易度連動（IR2-15）はこの後。
- ID はカテゴリ接頭辞＋連番（keigo5〜 のように既存の続き）。

## 方針変更（2026-11-22・本人の指示）
- 問題数の拡大は「他のエージェントに作らせる」方式に変更。パソパソは送信用プロンプトを用意し（`docs/問題生成プロンプト_他エージェント用.md`）、戻ってきた「問題文＋正解のみ」のシートに選択肢・解説・出典照合を付けて組み込む。
- 図形が必要なタイプのクイズ（標識など）は、画像素材を使わずコードで図形を描いて表示する（Art.kt 方式で標識部品を作る）。生成側では問題文の先頭に【図形】の印を付けてもらう。
