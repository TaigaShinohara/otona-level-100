本人の指示「シンプルガラススキルでアプリ全体を見直して」を受けて適用。

色の役割は ART_DIRECTION のまま変えていない（紺＝主役、金＝レベルアップだけ）。ART_DIRECTION は v1.1 に更新済み。

## 適用範囲と面の内訳
- 土台（全画面共通）：3点グラデーション（生成り→淡色→紺の淡色）＋光3つ（左上＝紺淡色／右下＝金淡色／中央下＝青淡色、RenderEffect ぼかし約60px、API 31+。未満は放射グラデの柔らかさで代替）
- ホーム／結果の主パネル：読み物ガラス（白62%→54%）＋スペキュラハイライト、角丸28
- レベルバー：軌道＝読み物ガラス、進み＝紺ベタ（やんわりグラデ）、全丸
- タブバー：読み物ガラスの浮遊ピル（角丸24）、選択中は淡色ティントベタのピル
- 選択肢／判定ボタン：読み物ガラス（角丸20、押下＝ティントベタ）
- 暗記カード／カテゴリ箱：読み物ガラス（角丸24／20）
- 主アクション：紺ベタ（白+8%→黒−4%）、画面に1つだけ（復習画面の第2アクションはガラスに格下げ）
- レベルアップピル：金ベタ（やんわりグラデ）＋固定の濃紺文字
- ダーク：深紺グラデ土台＋読み物ガラス（白19%→13%）＋補助文字 #D8CFC2 を独立に用意
